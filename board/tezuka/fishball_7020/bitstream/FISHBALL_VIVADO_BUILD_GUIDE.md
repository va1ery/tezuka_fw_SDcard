## Architecture Overview

```
┌─────────────────────────────────────────────────────────┐
│                  Zynq Z7020 (Fishball)                  │
│                                                         │
│  ┌──────────┐    ┌──────────────────────────────────┐  │
│  │  ARM PS  │    │        FPGA Fabric (PL)          │  │
│  │          │    │                                    │  │
│  │ S_AXI_HP0├────┤ m_axi_iq_stream   ← NEW RING BUF│  │
│  │ S_AXI_HP1├────┤ m_axi_spectrometer (waterfall)   │  │
│  │ S_AXI_HP2├────┤ m_axi_recorder + ADC/DAC DMA    │  │
│  │          │    │                                    │  │
│  │ AXI-Lite ├────┤ s_axi_lite (register control)    │  │
│  │          │    │                                    │  │
│  │  IRQ[11] ├────┤ interrupt_out (recorder)          │  │
│  │  IRQ[10] ├────┤ iq_stream_interrupt_out ← NEW    │  │
│  └──────────┘    └──────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

**HP Port allocation:**
| Port | AXI Master | Clock | Purpose |
|------|-----------|-------|---------|
| HP0  | m_axi_iq_stream | 62.5 MHz (clk_out1) | **NEW** IQ ring buffer DMA |
| HP1  | m_axi_spectrometer | 62.5 MHz (clk_out1) | Waterfall/spectrum |
| HP2  | m_axi_recorder + adc_dma + dac_dma | 100 MHz (sys_cpu_clk) | Recording + IIO DMA |

## Build Steps

### Step 1: Generate Verilog from Amaranth (already done)

The `maia_sdr.v` was already generated by the simulation scripts. To regenerate:
```bash
cd maia-hdl
PYTHONPATH=".:$PYTHONPATH" python3 -m maia_hdl.maia_sdr --config maia_iio maia_sdr.v
```

### Step 2: Build IP Cores (Vivado batch mode)

This packages `maia_sdr.v` as a Vivado IP core:
```bash
cd maia-hdl
make -C ip
```
This creates `ip/maia-sdr/maia_iio/` with the packaged IP.

### Step 3: Build ADI Library IP Cores

```bash
cd maia-hdl
make -C adi-hdl/library
```
This builds `axi_ad9361`, `axi_dmac`, `util_cpack2`, `util_upack2`.

### Step 4: Build Fishball IIO Project (Full Synthesis)

```bash
cd maia-hdl/projects/fishball_iio
make
```

**This is the long step** — takes 2-6 hours depending on CPU. It will:
1. Create the Vivado project targeting `xc7z020clg400-1`
2. Build the block design with all IP cores
3. Wire `m_axi_iq_stream` → `S_AXI_HP0`
4. Run synthesis → implementation → bitstream generation
5. Export `system_top.xsa`

Output: `projects/fishball_iio/fishball.sdk/system_top.xsa`

### Step 5: Copy XSA to Tezuka Firmware

```bash
cp projects/fishball_iio/fishball.sdk/system_top.xsa \
   /path/to/tezuka_fw-0.2.4/board/tezuka/fishball_7020/bitstream/maia-iio/system_top.xsa
```

### Step 6: Build Tezuka Firmware

Use the existing build script:
```
C:\Users\Andy\Downloads\maia-sdr-main\build_tezuka_patched.bat
```

### Step 7: Flash to Fishball

Copy the output `.frm` file to the Fishball via USB mass storage mode.

## Key Differences from plutoplus_iio

1. **FPGA Part**: `xc7z020clg400-1` (was `xc7z010clg400-1`)
   - Z7020 has 2x the LUTs, BRAMs, and DSP slices vs Z7010
   - Same CLG400 package (pin-compatible)

2. **IQ Stream Ring Buffer**: New `m_axi_iq_stream` AXI master port
   - Connected to `S_AXI_HP0` (previously unused)
   - Enables continuous high-bandwidth IQ streaming to DDR
   - Interrupt on `In10` (was tied to GND)

3. **Project Name**: `fishball` (instead of `plutoplus`)

## Troubleshooting

### Vivado not found
```bash
source /tools/Xilinx/Vivado/2023.2/settings64.sh
```

### adi-hdl not found
```bash
cd maia-hdl && git submodule update --init --recursive adi-hdl
```

### IP core version mismatch
Clean and rebuild:
```bash
make -C ip clean && make -C ip
```

### Timing failure
The Z7020 has more resources than Z7010, so timing should be easier.
If timing fails, try:
```bash
# In Vivado TCL console:
set_property strategy Performance_ExplorePostRoutePhysOpt [get_runs impl_1]
```
(Already set in system_project.tcl)
